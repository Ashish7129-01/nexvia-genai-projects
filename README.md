# Nexvia Generative AI Projects
This repository contains two Generative AI engineering projects.
## GENAI-01: Enterprise RAG Knowledge Platform
A document question-answering system with document ingestion,
retrieval, access controls, and cited AI responses.
## GENAI-04: Multimodal AI Studio
A Streamlit-based prototype supporting text generation,
image generation, speech-to-text, text-to-speech,
video analysis, and prompt safety checks.
## Repository Structure
- GENAI-01/ - Enterprise RAG Knowledge Platform
- GENAI-04/ - Multimodal AI Studio
## Architecture
GENAI-01:
Documents -> Ingestion -> Retrieval -> LLM -> Cited Answers
GENAI-04:
Streamlit Dashboard -> AI Modules -> AI Services
Text prompts -> Safety Checker -> AI Generation
